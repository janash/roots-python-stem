# Instructor notebooks

Start with [the instructor table of contents](table_of_contents.ipynb).

The five numbered lesson notebooks contain completed examples, exercise solutions,
and instructor explanations. The introduction includes quiz answer keys and a
caught, intentional error demonstration. Six additional notebooks provide independent
solutions to the create-your-own-notebook exercises, including the optional Gibbs
energy challenge.

Keep this folder inside the repository: notebooks use the shared `data/`,
`si_data/`, `images/`, and `knowledge_checks/` resources. Select the repository's
`.venv` Python kernel and run cells from top to bottom. No notebook installs packages.
The pandas lesson writes `periodic_data_processed.csv` in this folder.

Each exercise solution includes its own imports and input data setup. The XPS
solutions document example background regions and distinguish raw peak-area
ratios from sensitivity-corrected atomic ratios. Plot interpretations and data
tables accompany the visualization solutions.

The student notebooks in the repository root are unchanged.
